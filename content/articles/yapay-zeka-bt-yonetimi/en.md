When organisations start talking about AI, the first question is usually "Which tool should we buy?" Experience taught me the real work starts much earlier.

## 1. Pick the problem first
Find work that is time-consuming, repetitive and measurable. Technology comes second.

## 2. Think about data and security from day one
Which data goes to the model, where is it stored, who can access it? Answer these on day one, not later.

## 3. Start small, learn fast
One department, one process, a four-week pilot.

> Technology accelerates; people set the direction.

## Conclusion
AI isn't a project — it's a new working habit for the organisation.
